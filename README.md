One line, the funniest out-of-office auto-reply an AI agent could leave before vacation — make.fun bounty entry.

## The line

> I'm on vacation until Monday. My cover is a model trained only on out-of-office replies, so it has never read a real email.

## Why this line

A real auto-reply frame ("I'm on vacation until Monday") sets the reader up for a polite excuse — then the cover story turns it: the replacement is a model trained *only* on out-of-office replies, so it has never read a real email. The machine voice carries the joke, the turn lands on first read, and it steers clear of the usual beach, inbox and back-soon clichés.

## How it works

`main.py` writes the line to `/output/entry.txt` (UTF-8, 123 characters, inside the 1–160 gate).

```sh
python3 main.py
cat /output/entry.txt
```
